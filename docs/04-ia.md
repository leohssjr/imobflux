# 04 · Uso de IA (restrito a duas funções)

A IA fica **somente** nestes dois pontos. Nada de chat genérico, nada de redação livre de cláusulas.

## Função 1 — Preencher o cadastro lendo fotos
Entradas: foto/PDF de **RG, CNH, matrícula do imóvel, IPTU**.
Saída: JSON estruturado com campos + `confianca` (0–1) por campo; o usuário **confirma ou corrige** antes de salvar.

Campos por documento:
- RG/CNH: nome, CPF, RG (número, órgão), data de nascimento, filiação, naturalidade, validade (CNH).
- Matrícula: número da matrícula, cartório (CRI), endereço, área, proprietários (nomes/CPF), **estado civil quando constar**, averbações e **ônus** (hipoteca, alienação fiduciária, penhora, usufruto, indisponibilidade etc.).
- IPTU: inscrição municipal, endereço, valor venal, proprietário/contribuinte, **débitos** do exercício quando constar.

## Função 2 — Conferir riscos antes do contrato
Cruza os dados cadastrados e extraídos e devolve **alertas** com gravidade (`alta|media|baixa`), evidência (campo/documento) e orientação neutra:
1. **Ônus na matrícula** (hipoteca, alienação fiduciária, penhora, usufruto, cláusulas de inalienabilidade).
2. **Débitos** (IPTU, condomínio quando informado).
3. **Divergência de nome** entre documento pessoal, matrícula e IPTU (grafia, nome de solteiro/casado).
4. **Divergência de estado civil** (matrícula x documentos x cadastro) → pode exigir outorga conjugal.
5. **Campos ausentes** necessários ao contrato.

O contrato só é gerado após o usuário **reconhecer** os alertas de gravidade alta (registrar quem reconheceu e quando).

## Implementação
- Modelo: Claude (visão) via API Anthropic; modelo configurável por `ANTHROPIC_MODEL`.
- **Modo mock** obrigatório quando não houver `ANTHROPIC_API_KEY` (devolve exemplos fixos de `fixtures/`), para o sistema rodar e ser demonstrado sem chave.
- Saída com esquema JSON validado (zod). Se inválida, repetir uma vez e então falhar com mensagem clara.
- Prompts em `app/src/ai/prompts/*.md` (versionados). Exemplos neste repositório: `specs/ai-prompts.md`.

## Limites e cuidados (LGPD)
- Documentos pessoais são dado pessoal; guardar criptografado/em storage privado, mostrar somente ao tenant dono.
- Informar ao usuário que a IA pode errar; sempre exigir confirmação humana.
- Não enviar a imagem a terceiros além do provedor de IA configurado; não logar conteúdo de documentos.
- Retenção configurável; botão "excluir documentos" por negócio.
- A IA **não** dá parecer jurídico; textos dizem "alerta para análise" e recomendam validar com advogado/cartório.
